# Entregas

Un solo archivo, siempre el mismo nombre: `avance.docx`.

Cada semana se actualiza, se hace commit y se etiqueta. Git conserva el
historial. No crear `avance_S11.docx`, `avance_S12.docx`, etc.

| Semana | Etiqueta |
|---|---|
| 11 | `v0.1-semana11` |
| 12 | `v0.2-semana12` |
| 13 | `v0.3-semana13` |
| 14 | `v0.9-semana14` |
| 15 | `v1.0.0` |
